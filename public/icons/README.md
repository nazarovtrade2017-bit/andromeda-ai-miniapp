# Логотипы активов

По умолчанию иконки рисует `public/icons.js` (флаги, значки монет, тикеры акций, пиктограммы сырья), файлы здесь не нужны.

Чтобы использовать **настоящие (лицензионные) логотипы**, положите файлы сюда и перечислите их в `manifest.json`.
Ключ задаёт один значок, поэтому у пары «флаг + флаг» подменяется только нужная половина:

```json
{
  "stock:AAPL": "aapl.svg",
  "stock:TSLA": "tsla.png",
  "crypto:BTC": "btc.svg",
  "crypto:ETH": "eth.svg",
  "flag:USD": "usd.svg",
  "cmd:gold": "gold.svg",
  "index:USD500": "sp500.svg"
}
```

| Тип | Ключ | Пример |
|---|---|---|
| акция | `stock:<тикер>` | `stock:AAPL` |
| криптовалюта | `crypto:<тикер>` | `crypto:BTC`, `crypto:BTCETF` |
| валюта (флаг) | `flag:<ISO>` | `flag:EUR`; регионы индексов: `ES`, `FR`, `DE`, `NL`, `HK` |
| сырьё | `cmd:<название-через-дефис>` | `cmd:gold`, `cmd:brent-oil`, `cmd:natural-gas` |
| индекс | `index:<флаг><номер>` | `index:USD500`, `index:DE30` |

Файл, которого нет в манифесте, остаётся встроенной иконкой. Логотипы компаний и бирж — товарные знаки: используйте только те, на которые у вас есть права.

## Что уже подключено

В папке лежат 95 иконок, нарезанных из авторского спрайта проекта (акции, криптовалюты, флаги, индексы, золото/серебро/нефть/газ), и они прописаны в `manifest.json`.
Остальные активы (флаги DE/FR/ES у индексов, платина, палладий, Pfizer, Palantir и др.) рисует встроенный `icons.js`.
Исходные иконки маленькие (42×42 px), на крупных размерах они слегка мягкие. Чтобы заменить иконку, положите файл и поменяйте имя в манифесте.
